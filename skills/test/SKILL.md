기록해 둔 몰랐던 것을 **인출 연습**으로 굳히는 첫 시험 스킬이다. TIL을 다시 읽게 하지 않고, 기억에서 꺼내 답하게 한다. 제대로 이해했다면 답할 수 있는 문제를 낸다.

# 경로와 공용 규칙
`<SKILL>`은 이 스킬의 기본 폴더, `<ROOT>`는 플러그인 루트(`<SKILL>/../..`)다.
- 경로: `<NOTES>`는 `${user_config.notes_path}`, `<GENIUS>`는 `${user_config.genius_path}`다. 셸에서는 공백이 있을 수 있으므로 항상 따옴표로 감싼다. 폴더나 파일이 없으면 만든다.
- 학습 로그 형식: `<ROOT>/references/learning-log-format.md`
- TIL 형식: `<ROOT>/references/til-format.md`
- 출제 원칙: `<ROOT>/references/exam-questions.md`
- 시험지 경로·형식·PDF 변환: `<ROOT>/references/exam-sheet.md`

# 1. 입력 해석
- **기본은 항상 손글씨로 푸는 PDF 시험지다.** `/genius:test`를 실행하면 묻지 말고 시험지를 만든다(3번). 기기(아이패드 등)는 가정하지 않는다.
- 인자에 `chat`이 있으면 **대화형 시험**(4번)으로 한 문제씩 진행한다.
- 예전 문법이 들어오면 한 줄로 알리고 이 스킬의 기본 동작을 따른다. `new`는 기본 동작이 됐고, 노트 이름은 더 받지 않는다(시험은 학습 로그와 TIL로만 낸다). `grade`, `check`, `review`는 각각 `/genius:grade`, `/genius:note`, `/genius:review`로 바뀌었다고 알리고 그 스킬을 따른다.

# 2. 대상 고르기
1. **대상 행:** 학습 로그에서 `유형`이 `질문` 또는 `이해 확인`이고, `이력`에 시험 결과(`정답`, `부분`, `오답`)가 아직 한 번도 없는 행. 없으면 "새로 시험 볼 몰랐던 것이 없다"고 알리고 끝낸다.
2. **근거:** 행마다 `<NOTES>`의 TIL에서 `몰랐던 것`과 같은 `##` 제목을 찾아 근거로 쓴다(`grep -rlF`). 같은 제목이 여러 날짜에 있으면 모두 읽는다. 제목은 무엇을 몰랐는지, 본문은 제대로 이해했다면 답할 수 있어야 하는 내용, 배경은 실무 상황 문제의 재료다. `노트` 칸이 TIL이 아닌 실제 노트면 그 노트도 함께 쓴다. 근거가 없는 행은 출제하지 말고 목록으로 알린다. TIL에 `(확신 낮음)`이나 나중에 채웠다는 `출처` 줄이 있으면 답안지에 그렇게 적어 둔다.
3. **문제 수:** 같은 개념의 행은 묶어 한 문제로 낸다. 7문제가 넘으면 오래된 행부터 7문제만 내고, 나머지는 다음 시험으로 넘긴다(행은 건드리지 않는다).
4. TIL 내용을 사용자에게 보여 주지 않는다. 시작 메시지에는 문제 수와 진행 방식(TIL을 보지 않고 풀기)만 짧게 알린다. 같은 대화에서 방금 그 내용을 물어봤다면 "하루 뒤에 풀면 더 정확하다"고 한 줄만 안내하고, 시험지는 그대로 만든다.

# 3. 시험지 만들기
1. 출제 원칙에 따라 문제를 만든다. 시험지에 **정답이나 힌트를 넣지 않는다.**
2. 답안지를 저장한다(경로는 `exam-sheet.md`, 내용은 `exam-questions.md`의 "답안지"). 문항마다 **원래 학습 로그 행(날짜, 문제)**을 적어 둔다. `grade`가 이것을 보고 새 행을 만들지 않고 원래 행을 갱신한다.
3. `exam-sheet.md`의 형식으로 시험지 HTML을 만들고 PDF로 변환해 확인한다.
4. 사용자에게 파일 위치(`<GENIUS>/시험`)만 짧게 알리고, 다 풀면 `/genius:grade`를 하도록 안내한다.
5. 이 시험은 학습 로그를 직접 고치지 않는다. 채점(`/genius:grade`) 때 원래 행이 갱신되고 복습 날짜가 정해진다.

# 4. 대화형 시험 (`chat`)
문제를 내고 답을 받는 것까지만 한다. 채점, 해설, 학습 로그 기록은 `/genius:grade chat`이 이 대화의 문답으로 한다.
- 대상은 2번과 같다. 시작 전에 3번과 같이 답안지를 저장한다(시험지 PDF는 만들지 않는다). 답안지 제목 끝에 ` (대화형)`을 붙인다.
- **한 번에 한 문제**만 낸다. 문제마다 `Q1.`처럼 번호를 붙여, 나중에 채점할 때 문답을 짝지을 수 있게 한다.
- 사용자가 답하면 판정, 정답, 힌트, 해설을 말하지 않고 다음 문제로 간다. "모르겠다"도 그대로 답으로 받는다.
- 마지막 문제의 답을 받으면 "이 대화에서 `/genius:grade chat`으로 채점하세요. 새 세션을 열거나 `/clear`하면 답이 사라집니다"라고 안내하고 끝낸다.

# 주의
- 응답은 한국어로 하고, 부연 설명에 em-dash(—)를 쓰지 않는다. 괄호나 줄 분리를 쓴다.
- 쓰기는 `<GENIUS>/.답안지/`(답안지), `<GENIUS>/시험/`(시험지)에만 한다. TIL 내용이 틀린 것 같으면 알리기만 하고, 고치는 것은 사용자가 요청할 때 한다.
- 시험 중에는 TIL 내용을 요약하거나 다시 설명해 주지 않는다. 사용자가 시험을 중단하고 설명을 요청하면 그때 응한다.
