모든 문항에 해설을 주는 채점 스킬이다. 맞힌 문항도 해설을 보면 제대로 알고 맞힌 것인지, 어쩌다 맞힌 것인지 가려진다.

# 경로와 공용 규칙
`<SKILL>`은 이 스킬의 기본 폴더, `<ROOT>`는 플러그인 루트(`<SKILL>/../..`)다.
- 경로: `<NOTES>`는 `${user_config.notes_path}`, `<GENIUS>`는 `${user_config.genius_path}`다. 셸에서는 공백이 있을 수 있으므로 항상 따옴표로 감싼다. 폴더나 파일이 없으면 만든다.
- 학습 로그 형식: `<ROOT>/references/learning-log-format.md`
- 채점 기준(판정, 해설, 답 표시, 결과 요약, 학습 로그 기록·갱신): `<ROOT>/references/grading.md`
- 시험지·답안지 경로: `<ROOT>/references/exam-sheet.md`

# 1. 푼 시험지 찾기
- 인자가 `chat`이면 PDF를 찾지 않고 **6. 대화형 채점**으로 간다.
- 인자로 파일을 주면 그 파일을 쓴다.
- 없으면 `<GENIUS>/시험`과 `<GENIUS>/복습`을 함께 보고 가장 최근에 수정된 `... 시험지.pdf`(또는 `... 답안.pdf`)를 쓴다.
- 이미 채점된 시험지(제목이 `해설지:`, 예전 파일은 `채점:`)는 다시 채점하지 않는다.
- 학습 로그를 쓰는 방법은 시험 종류마다 다르다.
  - **첫 시험**(`<GENIUS>/시험/...`, `/genius:test`로 본 시험): 새 행을 만들지 않고 원래 행을 갱신한다(`grading.md`의 "학습 로그 갱신 (첫 시험)").
  - **복습 시험**(`<GENIUS>/복습/...`): 원래 행을 갱신한다(`grading.md`의 "학습 로그 갱신 (복습 시험)").

# 2. 채점
1. 답안지와 근거(TIL, 노트)를 읽는다. 답안지에 적힌 원래 학습 로그 행도 읽는다.
2. 푼 시험지 PDF(또는 이미지)를 읽는다. PDF는 `pages`로 나눠서 본다.
3. 손글씨는 **읽은 내용을 문제별로 먼저 옮겨 적어 사용자에게 보여 주고, 맞는지 확인받은 뒤 채점한다.** 이때 `?`와 `(참고함)` 표시도 함께 옮겨 적는다. 알아보기 어려운 글자는 추측하지 말고 "이렇게 읽었는데 맞나요"라고 묻는다.
4. `grading.md`에 따라 문제별로 채점하고 모든 문항의 해설을 대화창에 보여 준다.
5. 손글씨 인식이 끝까지 불확실한 문제는 "판독 불가"로 표시하고 점수에서 제외한다.

# 3. 해설지 만들기
**문제마다 바로 아래에 해설을 넣은 해설지를 만든다.** 태블릿 마크업 필기(예: iPad 마크업)는 페이지마다 한 장의 이미지(stamp)로 저장될 수 있으므로, 문제 영역을 필기째 잘라 이미지로 만들고 그 아래에 해설을 붙여 PDF를 다시 만든다.
```bash
# 문제 번호("1.", "2." ...) 위치로 문제+필기 영역을 잘라 q1.png ... 로 저장 (아래 빈 공간은 자동으로 잘라냄)
# 마지막 인자는 채점 표시: 문제 순서대로 O(정답) / T(부분 정답, 세모) / X(오답)를 쉼표로 (예: O,T,X,O,X,X)
# 번호 위에 빨간 ○ △ ✕ 가 그려진다. `?` 정답은 일정상 부분 정답이지만 표시는 O로 한다.
python3 "<ROOT>/scripts/cropq.py" "<시험지.pdf>" <스크래치패드>/crops <문제 수> <원래 시험지 페이지 수> "O,T,X,..."
# crops/qN.png 를 <img>로 넣은 채점 HTML을 같은 스크래치패드 폴더에 만들고 변환
python3 "<ROOT>/scripts/html2pdf.py" <스크래치패드>/graded.html <스크래치패드>/graded.pdf
```
- 만든 PDF를 읽어 문제마다 필기와 해설이 맞게 붙었는지 확인한다.
- 확인되면 원래 시험지를 그 시험지가 있는 폴더의 `.원본/`(`<GENIUS>/시험/.원본/` 또는 `<GENIUS>/복습/.원본/`, 숨김 폴더)에 복사해 두고, 같은 이름으로 해설지를 덮어쓴다. 원본은 필기를 다시 고칠 수 있는 파일이다.

형식:
- 반 페이지 배치는 적용하지 않는다. 문항 블록(필기 이미지 + 해설 + 질문·내 이해 칸)을 `page-break-inside: avoid`로 이어 붙여, 대개 한 페이지에 한 문항이 들어가는 지금 배치를 유지한다(사용자 선호).
- 시험지와 같은 스타일. 제목 `해설지`(복습은 `복습 해설지`), 점수 한 줄(정답 N / 전체, 부분 정답 N개)과 "해설을 읽고 이해한 뒤, 이 파일을 닫고 오답노트를 쓰기".
- 문항마다 `.q` 블록(`page-break-inside: avoid`)에 `<img src="crops/qN.png" style="width:100%">`(문제와 내 필기), 그 바로 아래 해설 상자(왼쪽 회색 선, 옅은 배경)를 둔다.
- 해설 상자 맨 위에는 `해설`이라는 회색 라벨만 둔다. 정답 여부는 번호 위의 ○ △ ✕로 알 수 있으므로 판정 글자는 넣지 않는다. 그 아래 `grading.md`의 해설 항목(모범 답안 요점, 내 답과의 차이, 왜 그렇게 생각하기 쉬운지, 노트에서 볼 곳)을 넣는다. 복습이면 이전 오답노트 정리도 넣는다(찾는 방법은 `note` 스킬의 "이전 정리 찾기").
- 채점 뒤에 사용자가 더 쓴 필기가 있으면 점수에는 넣지 않고, 해설에 "채점 후 쓴 답에 대해" 한 줄로 짚는다.
- 각 `.q` 블록 맨 앞에 숨김 표시를 넣는다: `.q { position: relative; }`, `.mk { position: absolute; top: 0; left: 0; color: #fff; font-size: 2pt; line-height: 2pt; }`, `<span class="mk">@Q1@</span>`. `/genius:note`가 이 표시로 문항 블록을 잘라낸다.
- 해설 상자 바로 아래에 **"질문·내 이해" 빈칸**(테두리 점선, 약 80pt, 왼쪽 위에 회색 작은 글씨로 `질문 · 내 이해`)을 둔다. 사용자가 해설을 읽으며 모르는 표현이나 자기가 이해한 내용을 필기하는 곳이고, `/genius:note`가 읽는다.

# 4. 결과 요약과 학습 로그
`grading.md`에 따라 결과 요약을 주고 학습 로그에 기록한다. 첫 시험과 복습 모두 새 행을 만들지 않고 원래 행을 갱신한다. 답안지의 문항마다 채점 결과와 오답노트 종류를 적는다(`grading.md`의 "답안지에 채점 결과 남기기"). `/genius:note`가 이것으로 오답노트 문항을 고른다.

# 5. 마무리 안내
- 문제마다 해설이 들어갔다는 것을 알린다.
- 해설을 읽으며 모르는 표현이나 내가 이해한 것을 "질문·내 이해" 칸에 적은 뒤 `/genius:note`를 하라고 안내한다. note가 필기를 확인하고 오답노트를 만든다. 적은 게 없어도 `/genius:note`로 오답노트를 받는다.

# 6. 대화형 채점 (`chat`)
`/genius:test chat`이나 `/genius:review chat`으로 본 시험을 같은 대화 안에서 채점한다.
1. 이 대화에서 가장 최근 대화형 시험의 문답(`Q1.`부터 마지막 문제까지와 각 답)을 찾는다. 없으면 "이 대화에 채점할 대화형 시험이 없다. 시험을 본 대화에서 실행해야 한다"고 알리고 끝낸다. 대화가 요약되어 답 원문이 남아 있지 않은 문항은 추측하지 말고 "판독 불가"로 처리한다.
2. `<GENIUS>/.답안지/`에서 제목 끝이 ` (대화형)`인 가장 최근 답안지를 읽는다. 시험 종류(첫 시험, 복습 시험)와 원래 행은 1번과 같이 답안지로 정한다.
3. 채점에 들어가기 전에 문제별로 사용자 답을 옮겨 적어 보여 주고 맞는지 확인받는다.
4. `grading.md`에 따라 채점하고 모든 문항의 해설을 대화창에 보여 준다.
5. **해설지 PDF를 만든다.** 대화에서 본 시험도 손글씨 모드처럼 다시 볼 수 있게 하기 위해서다. 3번의 형식을 따르되 문제를 잘라 낸 이미지 대신 다음을 넣는다.
   - 번호(`1.`)와 문제 문장(답안지의 문제 그대로)
   - **내 답** 상자: 대화에서 받은 답을 원문 그대로(고쳐 쓰거나 요약하지 않는다). `?`, `(참고함)` 표시도 그대로.
   - 번호 옆에 빨간 ○ △ ✕(HTML로 그린다, 색 `#d91f1a`)
   - 그 아래 해설 상자, 숨김 표시 `@QN@`, "질문·내 이해" 빈칸은 3번과 같다. 그래서 `/genius:note`(기본, `chat` 모두)를 손글씨 모드와 똑같이 쓸 수 있다.
   - 경로: 첫 시험 `<GENIUS>/시험/YYYY-MM-DD 해설지 (대화형).pdf`, 복습 `<GENIUS>/복습/YYYY-MM-DD 복습 해설지 (대화형).pdf`. 제목은 3번과 같이 `해설지`(복습은 `복습 해설지`).
   - `html2pdf.py`로 변환하고 PDF를 읽어 확인한다.
6. 4번과 같이 결과 요약을 주고 학습 로그에 기록하거나 원래 행을 갱신한다.
7. 5번(마무리 안내)과 같이 안내하고, 오답노트를 대화로 쓰고 싶으면 `/genius:note chat`도 된다고 알린다.

# 주의
- 응답은 한국어로 하고, 부연 설명에 em-dash(—)를 쓰지 않는다.
- 쓰기는 `<GENIUS>/시험/`, `<GENIUS>/복습/`(해설지와 `.원본/`), `<GENIUS>/학습 로그.md`, 답안지의 채점 결과 줄에만 한다. 대화형 채점(`chat`)도 같은 폴더에 해설지를 만든다(덮어쓸 원본이 없으므로 `.원본/`은 쓰지 않는다). 답안지(`<GENIUS>/.답안지/`)에는 채점 결과 줄만 덧붙인다.
